## Open without installing RTL Lens

[Download the offline report ZIP](https://github.com/y38283004-crypto/rtl-lens/raw/refs/heads/main/docs/demo/rtl-lens-demo.zip),
extract it, and open `width-warning.html` or `width-fixed.html` in a browser.
The reports include their CSS and JavaScript, so no server or network connection
is needed to view them. GitHub's normal HTML file viewer displays source text;
open a saved file to use report filters and relationship search.

To regenerate reports, use the commands in the example walkthrough. This is a
PySlang-only example; dual-engine CI evidence is separate. The zero-finding fixed
scan is a static diagnostic observation rather than functional verification.
Timestamps and durations are observations from the recorded runs.
