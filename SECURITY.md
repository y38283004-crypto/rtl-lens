# Security Policy

## Reporting a vulnerability

Do **not** report a suspected vulnerability in a public issue or public Issue
Form. Use GitHub **Security → Advisories → Report a vulnerability** for this
repository so maintainers can assess it privately.

Include the affected RTL Lens version or commit, operating system and Python
version, clear reproduction steps or a minimal sanitized example, the expected
and observed behavior, impact, and any relevant **sanitized** logs. Remove
secrets, tokens, credentials, private source, IP addresses, and customer data
before submitting a report.

## Supported versions

RTL Lens is pre-release software. No stable version is supported yet; reports
against current development are still welcome through the private reporting UI.

## Handling reports

Maintainers will use the private advisory discussion to request clarification,
coordinate a fix, and decide whether a public disclosure is appropriate. This
policy sets no response-time guarantee and does not publish an email contact.
